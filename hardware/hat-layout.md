## J4 = 零位错位排母（详见 pinmap.md）

## 功能分区（按原理图坐标，单位 0.01in）

原理图原件摆放确实杂乱（分区标签少、跨区拉线长），按坐标归组如下：

### ① 左上：J4 排母 + I2C 上拉（x 130–460, y 335–530 / 210–300）
- J4(260,430) FH-00339 2×20P 排母，bottom 面
- **H1(565,1050) = ToF 接口**（2026-10-25 用户把原 J5 的 JST-SH 4P 座换成 1×4P 2.54 直插排针，
  XFCN PZ254V-11-04P，LCSC C2691448，针高 6.1mm）。**非 Qwiic 标准脚序，接线前必看**：

  | H1 脚 | 网络 | 说明 |
  |---|---|---|
  | 1 | 3V3 | 电源 |
  | 2 | GND | 地 |
  | 3 | GPIO03_I2C_SCL | SCL |
  | 4 | GPIO02_I2C_SDA | SDA |

  ⚠️ 原 J5（JST-SH 4P）是 Qwiic 标准序 1=GND / 2=3V3 / 3=SDA / 4=SCL，H1 把电源两根和 SDA/SCL
  都换了位置。**只能用杜邦线按编号逐根接模块的 PTH，禁止插现成的 Qwiic 4 芯转接线**（会把 3V3/GND 反接到
  VL53L5CX 模块上）。模块侧（VL53L5X V2）PTH 丝印为 GND / 3V3 / SDA / SCL。
- R12/R13 10k I2C 上拉（与 TLV320AIC3104 共用 I2C3；ToF 默认地址 0x29）

### ② 左中：DXL 半双工方向切换（x 195–980, y 790–1300）
- R26(240,820) 10k TX 上拉；R27(240,920) 10k + Q1(410,880) MMBT3906 + R28(410,1020) 20k：方向控制
- U7(600,910) SN74LVC1G126 TX 缓冲；U6(800,1000) SN74LVC1G125 RX；U5(1140,980) 74LVC1G08 RX 门控；R29(980,1080) 10k 门控使能；R31(980,870) 10k RX 上拉
  （2026-10-25：U5 由用户补全料号 → UMW **SN74LVC1G08DBVR**，LCSC C434068，TSOT-23-5。
  引脚核对：1=A←`TTL_RX_RAW`、2=B←`RX_GATE_EN`、3=GND、4=Y→`GPIO15_UART_RX`、5=VCC→3V3，与门接法与原图一致）
- C16/C17/C18 去耦(500/580/660,1130–1200)

### ③ 中上：电源（x 15–620, y 100–500）
- **2026-10-25 改动一：拆除板载 DC-DC 与理想二极管链**（U9 AP63205、L4 6.8µH/3A、C20 自举 100nF、
  Q2 SI2312、U10 LM5050-1、R8 100R、C39 100nF 全部删除），5V 改为外部输入。
- **2026-10-25 改动二：D1 换成 PTC + TVS**。原 D1 BAT54SW 三个脚只接了 1=GND、3=5V，中间脚悬空，
  两只串联二极管都不成回路，实际等于没装。现改为：
  - U11(140,120) 2P 螺钉端子：pin1 → **5V_VIN**，pin2 → GND
  - **F1(280,325) mSMD150-16V 自恢复保险丝**（1.5A 保持 / 3A 跳闸 / 16V，F1812，C70122）：5V_VIN → 5V
  - **D1(280,430) SMAJ5.0A 单向 TVS**（SMA/DO-214AC，C143135）：K→5V，A→GND
- C21/C22(375,125/180) 22µF 保留在 5V 母线上做输入储能（功放峰值电流大，两颗都留）。
- **2026-10-25 改动三：5V 上两颗重复的 1µF（C42/C43）删除**。它们原本挂在 5V↔GND，功能与 C21/C22、
  C5/C7 重复，且**没有**接到麦克风偏置节点上（偏置由 R22/R23 从 5V 分出），属于既冗余又没起作用。
  腾出的位置改放两颗偏置去耦：**C44 = 100nF / MIC_EXT_L_BIAS↔GND**、**C45 = 100nF / MIC_EXT_R_BIAS↔GND**
  （0603 X7R 50V，CC0603KRX7R9BB104，LCSC C14663），压住偏置线上的噪声。
- C15（10µF）已删除；**BATT_IN 网络取消**，原 J13-2/J14-2 改为 **SERVO_VPASS** 直通网：
  只让舵机电池在 J13↔J14 之间过线，HAT 不再从电池取电（舵机电源另做 HUB 板，见 docs/02）。

### ④ 中右：DXL 总线端（x 1300, y 1130–1300）
- J13/J14(1300,1130/1250) A2007 2.0mm 3P 舵机口 ×2
- R32(750,820) 10k 数据上拉；**R33 已删除（2026-10-25）**，DXL_DATA_INT 与 DXL_DATA_CLAMPED 合并为同一网络；**R35(1080,1280) 22Ω**（用户改，原 TH1 PTC）；D4(920,1220) 5.1V 钳位

### ⑤ 右上：codec 时钟与 1V8（x 1750–2100, y 85–700）
- Y1(2045,195) 12MHz + C14(2155,255)；R6(2215,155) 10k codec 复位 + C38
- U3(2015,485) XC6206P182 1V8 LDO + C12/C13/C26
  （2026-10-25：3V3 上重复的 10µF **C37 已删除**，只留 C13 一颗，靠近 LDO 输入更有用）

### ⑥ 右中：codec 本体（x 2000–2950, y 440–700）
- U2(2515,455) TLV320AIC3104IRHBR + C27/C28/C30/C32/C35/C36 去耦
  （2026-10-25 精简：删掉重复的 1µF 电源去耦 C29/C31，每电源域 1 颗 1µF + 每脚 1 颗 100nF 足够）
  （2026-10-25 精简：**R7 0Ω（MIC2L→GND）已删除**，U2-14 的 stub 网络名直接改成 `GND`——0Ω 短接本就是这个效果，
  省一颗 0603 且 U2-14 不再悬空。网表实测：`GND` 含 U2-14，`MIC2L_GND_LINK` 网络已不存在）

### ⑦ 右下：功放与麦克风（x 1750–2950, y 940–1830）
- U1(2200,1300) PAM8406D 5W 立体声 D 类 + R3/R4/R5(1910,1390–1570) 0R SHDN/MUTE/MODE 拉高
  （2026-10-25 精简：删掉 PVDD 上重复的 1µF C4/C6，只留贴脚 10µF C5/C7；C33/C34 属 VDD 滤波，保留）
- FB1(2120,990) 600R 磁珠；FB2/FB3(2480,1190/1330) 120R 喇叭滤波 + C8/C9 220pF；J1(2840,1260) SPK R
- **MK1 板载 MEMS 麦 + C10/C11 已于 2026-10-25 按用户要求删除**；U2-16（MIC2R/LINE2R）现悬空，
  外接麦走 J2/J9 + R22/R23 10k 偏置 + **C40/C41 1µF 交流耦合 + C44/C45 100nF 偏置去耦**
  （网表实测：`MIC_EXT_L_BIAS` = C41-2 / R22-1 / J2-2 / C44-2；`MIC_EXT_R_BIAS` = C40-2 / R23-1 / J9-2 / C45-2）
- **左声道已按用户要求删除**（2026-10-25）：删 C1（1µF 耦合）、R1（10k 输入电阻）、`CODEC_LEFT_LOP` 与
  `AMP_L_P_RAW`/`AMP_L_N_RAW` 的 stub；U1-7（INL）短接 stub 直接接 `GND`，U2-27（LEFT_LOP）与 U1-1/U1-3 悬空。
  右声道完全不动：`CODEC_RIGHT_LOP` = U2-29 + C2-1 → C2 → R2 → `AMP_INR` = U1-10 → J1。
  （网表实测：`GND` 含 U1-7；`AMP_INL`/`AMP_INL_AC`/`CODEC_LEFT_LOP` 三个网络已消失）

### ⑧ 孤角：RX 指示灯（x 360–780, y 2290，远离所有区块）
- R34(360,2290) 1k + D5(780,2290) 绿 LED：GPIO15_UART_RX → R34 → D5 → GND
